# GitHub Repo Parser

Парсер топовых Python-репозиториев с GitHub API. Проект демонстрирует навыки работы с REST API, обработки структурированных данных и автоматизации выгрузки в табличный формат.

## О проекте

Скрипт собирает данные о 200 самых популярных Python-репозиториях (по количеству звёзд) через GitHub Search API и сохраняет результат в Excel-файл. Проект подходит для быстрого получения бенчмарка по экосистеме Python или формирования выборки для анализа.

## Навыки и технологии

- **Python Core**: работа с модулями, функциями, обработкой исключений.
- **HTTP-запросы**: библиотека `requests`, работа с заголовками и параметрами API.
- **Обработка данных**: нормализация JSON-ответов, фильтрация полей.
- **Табличные данные**: `pandas` для структурирования, `openpyxl` для экспорта в Excel.
- **Автоматизация**: пакетная обработка пагинации (2 страницы по 100 элементов).

## Возможности

- Запрос к GitHub Search API по критерию `language:python`.
- Сортировка по убыванию количества звёзд (`stars`, desc).
- Выгрузка 200 репозиториев (2 страницы по 100).
- Сохранение в `github_python_repos.xlsx` (5 полей: name, html_url, stargazers_count, created_at, description).
- Поддержка GitHub Token для увеличения лимита запросов.

## Установка и запуск

1. Клонируй репозиторий или создай папку проекта.
2. Установи зависимости:

   ```bash
   pip install -r requirements.txt
3.При необходимости вставь GitHub Token в main.py в переменную TOKEN (для увеличения лимита запросов).

4.Запусти скрипт:

bash
python main.py
5.Результат — файл github_python_repos.xlsx в корне проекта.

Структура проекта
main.py — основной скрипт (сбор, нормализация, экспорт).
requirements.txt — список зависимостей.
.gitignore — исключения для коммитов.
github_python_repos.xlsx — выходной файл (генерируется автоматически).
Зависимости
requests — HTTP-запросы к GitHub API.
pandas — работа с табличными данными.
openpyxl — экспорт в Excel.
Как использовать результаты
Анализ трендов: изучение дат создания топовых репозиториев.
Бенчмарк: сравнение количества звёзд для оценки популярности инструментов.
Выборка: формирование списка проектов для ручного изучения или тестирования.
